## Overview

**Food Express** is a comprehensive mobile application designed to simplify the food ordering experience. It allows users to explore menus, manage their shopping cart, place and track orders, and receive real-time updates on order status and promotions. The app enhances convenience with push notifications for special offers and order alerts. With a focus on a seamless user experience, Food Express aims to make food ordering fast, efficient, and enjoyable for users across both iOS and Android platforms.

## Key Features

- **User Profile Management**: Create and manage user profiles.
- **Menu Browsing**: Explore various food items and their details.
- **Shopping Cart**: Add, remove, and view items in the shopping cart.
- **Order Placement and Tracking**: Place orders, view order history, and track order status.
- **Push Notifications**: Receive real-time updates on order status, promotions, and offers.
- **Promocode**: Apply promocodes for discounts and special offers during checkout.







## Tech Stack

### Frontend
- **Flutter**: Cross-platform app development for iOS and Android.

### Backend
- **Node.js & Express.js**: RESTful APIs for user management, menu handling, and orders.
- **MongoDB**: NoSQL database for user data and orders.
- **Vercel**: Deployment and hosting for backend services.

### Firebase
- **Authentication**: Manage user sign-ups, logins, and password resets.
- **Push Notifications**: Send real-time updates via Firebase Cloud Messaging (FCM).
